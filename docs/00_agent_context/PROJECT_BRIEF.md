## Vision Statement

**بوابة قسم الرياضيات الذكية** is an AI-powered academic portal that converts dense university lecture PDFs into engaging, multi-modal learning assets — delivered to Mathematics Education undergraduates at Beni-Suef University through a beautiful, gamified web interface in Egyptian Arabic.

> **The core promise:** A student who missed a lecture, or who is anxious about a coming exam, can open the portal, tap "كمّل من حيث وقفت", and be learning within 2 seconds — in familiar Egyptian dialect, at the pace that fits their life.

---

## Target Users

### Primary — Mathematics Students
- **Who:** Undergraduate students (Levels 1–4), Faculty of Science, Mathematics Education program, Beni-Suef University.
- **Device:** Primarily mid-range Android smartphones (360px–420px viewport) on campus Wi-Fi.
- **Pain Points:** Dense mathematical PDFs impossible to study from, exam anxiety, inconsistent lecture attendance, language barrier (classical Arabic vs. Egyptian dialect).
- **Motivation:** Pass exams, understand course material, feel academically capable.

### Secondary — Professors & Teaching Assistants
- **Who:** Professors who deliver lectures; TAs who support students.
- **Use:** Review how their lecture content was summarized/explained by the AI. No direct portal interaction today.

### Admin — Portal Administrator
- **Who:** The developer (you — محمد عبد القادر).
- **Use:** Upload raw PDFs → trigger AI pipeline → verify assets → publish to students.
- **Access:** `/admin` route (protected by Supabase service role key).

## Core Feature Set

### ✅ Live in Production

| Feature | Description |
|---|---|
| **Subject Grid** | 11 departmental subjects, each with lecture cards, doctor tracks, and semester filtering |
| **Multi-Doctor Tracks** | Single subject card supports dual-professor courses (e.g., دكتورة مروة + دكتور وليد) with isolated syllabi |
| **Audio Podcast** | Egyptian Arabic conversational podcast summary generated by NotebookLM, streamed from Telegram CDN |
| **Whiteboard Video** | Blackboard animation video streamed from Telegram CDN |
| **Interactive Quiz** | 5–10 multiple choice comprehension questions per lecture |
| **Flashcards** | Key concept flash cards (spaced repetition ready) |
| **Study Guide** | Full formatted study notes with KaTeX mathematical formulae |
| **Gamification — XP & Levels** | Points for audio, video, quiz, flashcard, study guide activities |
| **Gamification — Streaks** | Daily study streak tracking in Cairo timezone |
| **Gamification — Badges** | Achievement unlock system (10+ badge types) |
| **Leaderboard** | Anonymous cohort ranking |
| **Smart Resume** | One-tap resume from exact last position (per-tab, per-lecture) |
| **5-Minute Micro-Session** | Quick study mode: 3 cards + 1 quiz question |
| **Ethical Wrap-Up Modal** | Supportive session summary encouraging healthy exit |
| **Mistake Notebook** | Leitner spaced repetition system for wrong quiz answers |
| **Dark / Light Mode** | System-aware + manual toggle |
| **Bilingual Math** | KaTeX with forced LTR, isolated from Arabic RTL layout |

## Non-Functional Requirements

| Requirement | Target |
|---|---|
| **Time to first action** | < 2 seconds from homepage load |
| **Mobile viewport** | 360px minimum, touch targets ≥ 44×44px |
| **Math rendering** | KaTeX, LTR, zero RTL interference |
| **Offline resilience** | IndexedDB outbox queues XP events if network drops |
| **Data integrity** | All XP/streak writes are idempotent RPC transactions |
| **Language** | Egyptian Arabic (عامية مصرية) for all student-facing copy |
| **Zero cost hosting** | Cloudflare Pages (frontend) + Render free tier (backend) + Telegram CDN (media) |
| **Privacy** | Anonymous auth by default; no email required |

## Constraints & Decisions

| Decision | Rationale |
|---|---|
| Telegram as CDN | Free, unlimited storage, 2GB/file, globally fast via MTProto |
| Anonymous Supabase auth | Zero friction — no email/password; students get real `auth.uid()` |
| Cairo timezone (not UTC) | University day boundary = Cairo midnight, not UTC midnight |
| SECURITY DEFINER RPCs only | Prevents client-side XP manipulation; single source of truth |
| No SM-2 algorithm | Replaced with deterministic Leitner boxes (transparent to students) |
| No push notifications yet | Service worker complexity vs. benefit; planned post-MVP |
